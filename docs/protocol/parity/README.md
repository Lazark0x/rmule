## Row schema

| Column | Meaning |
|---|---|
| Behavior | opcode + hex + short semantic, e.g. `OP_LOGINREQUEST 0x01` — login |
| Dir | rmule perspective: `E` emit, `C` consume, `B` both |
| aMule cite | SHA permalink(s) into 2.3.3 source |
| Disposition | target bar: `full` / `graceful` / `n-a` |
| Status | `at parity`, `partial`, `missing` or `exempt` (below) |
| rmule site | the file, as a path under `crates/` (or `apps/` for an app), and the type or function that carries the behavior |
| Evidence | a committed fixture or capture path, `code only`, or `—` (below) |
| Note | what differs when `partial`, why when `exempt`; otherwise what is worth knowing |

**Status.**

- `at parity` — the rmule site does what aMule does to the disposition's bar:
  for `full`, the behavior itself; for `graceful`, parse, a minimal safe answer,
  never a protocol break.
- `partial` — part of the behavior ships; the Note names the part that does not.
- `missing` — nothing ships.
- `exempt` — rmule does not match aMule on purpose; the Note gives the reason
  (an extinct peer generation, migration import out of scope, or a ruling such
  as [ADR-0095](../../adr/0095-connecting-is-the-operators-act.md)).

**Evidence.**

- A path under `crates/*/tests/fixtures/` — counterparty-authored bytes from a
  pinned local counterparty (aMule, eMule Qt, Lugdunum, ed2k-server, eNode),
  cut from a capture and never edited. For an emit row it is the counterparty's
  answer to rmule's bytes: rmule's own bytes are never counted as evidence.
- `code only` — the behavior is in the code and its tests, but no counterparty
  bytes are committed. Handwritten test vectors and bench runs whose bytes were
  not kept count here.
- `—` — nothing to prove: only on `missing` and `exempt` rows.

## Disposition rules

1. `full` — affects transfers, source discovery, upload fairness, connectivity (callbacks/firewall), network health, or obfuscation.
2. `graceful` — human-layer semantics or optional ops: parse, minimal safe response, never protocol-break, no feature semantics.
3. `n-a` — amuled implements it but rmule skips entirely; the row is `exempt` and its Note carries the one-line justification.
