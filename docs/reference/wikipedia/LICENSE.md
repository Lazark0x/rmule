# Wikipedia content license

All cached pages from `en.wikipedia.org` are available under the Creative Commons Attribution-ShareAlike 4.0 International License (CC-BY-SA-4.0). Wikipedia content is also dual-licensed under the GNU Free Documentation License for historical compatibility.

Reference: <https://en.wikipedia.org/wiki/Wikipedia:Copyrights>
License text: <https://creativecommons.org/licenses/by-sa/4.0/>

Sidecar files record the license as `CC-BY-SA-4.0` because that is Wikipedia's default attribution path.

This LICENSE.md is rmule-authored metadata about the upstream license. The raw page bytes themselves are gitignored and not redistributed from this repository; see ADR-0013.
