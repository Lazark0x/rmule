# aMule wiki content license

All cached pages from `wiki.amule.org` are content from the aMule project FAQ wiki.

The wiki page footer does not display a `$wgRightsText` license line, but the wiki's dedicated copyrights page states:

> All text is available under the terms of the GNU Free Documentation License available at http://www.gnu.org/copyleft/fdl.html.

Source: <https://wiki.amule.org/wiki/AMule_Project_FAQ:Copyrights>

The URL <http://www.gnu.org/copyleft/fdl.html> is the versionless GNU FDL pointer maintained by the FSF; sidecar files record the license as `GFDL` because the wiki does not pin a specific version.

This LICENSE.md is rmule-authored metadata about the upstream license. The raw wiki content itself is gitignored and not redistributed from this repository; see ADR-0013.
